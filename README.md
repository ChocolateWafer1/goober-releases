# Goober downloads

Every version of Goober, and the Firefly Launcher (once the Goober Launcher) that installs them.

Get the launcher once from the [launcher-2.2.1 release](https://github.com/ChocolateWafer1/goober-releases/releases/tag/launcher-2.2.1):
unzip it and run Firefly Launcher.exe. It installs and updates Goober, Isom and House Rules, and keeps itself up to date.
A Goober Launcher you already have updates itself into the Firefly Launcher.
